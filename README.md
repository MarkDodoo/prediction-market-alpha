# Prediction Markets Alpha & Arbitrage Discovery

## 🎯 Project Objective
This project utilizes State-of-the-Art (SOTA) LLMs combined with Analytics/ML to identify mispriced opportunities (Alpha) and price discrepancies (Arbitrage) in niche prediction markets.

## 🛠️ Tech Stack
- **Languages:** Python
- **Markets:** Polymarket (via `py-clob-client`), Kalshi
- **AI/LLM:** OpenAI GPT-4o / LangChain for news synthesis and probability estimation
- **Validation:** `backtesting.py` for historical strategy verification

## 📂 Research Areas
1. **News Sentiment vs. Market Price:** Using LLMs to parse niche news sources and compare their implied probability against market odds.
2. **Cross-Platform Arbitrage:** Identifying price gaps between Kalshi (regulated) and Polymarket (crypto-native) on identical events.
3. **Legal/Policy Impact:** Feeding raw legislative text to LLMs to predict the outcome of regulatory decisions.
